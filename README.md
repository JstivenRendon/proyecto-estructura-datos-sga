# Proyecto Estructura de Datos SGA

## Inicio de la aplicación

El punto de entrada de la interfaz es `gui.Main` (`src/sga/gui/Main.java`). En VS Code, abre la carpeta del proyecto y usa **Run Code** sobre `Main.java`, `Ctrl+F5` o **Terminal > Ejecutar tarea... > SGA: Ejecutar sin depurar**. Las pestañas comparten una instancia de `SistemaAlojamiento`.
