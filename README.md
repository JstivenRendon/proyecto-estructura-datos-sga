# Proyecto Estructura de Datos SGA

## Inicio de la aplicación

El punto de entrada de la interfaz es `gui.Main` (`src/sga/gui/Main.java`). En VS Code, abre la carpeta del proyecto y ejecuta la configuración **SGA - gui.Main** con `F5`; las pestañas de reservas, calendario, recepción, preparación, mapa y estadísticas comparten la misma instancia de `SistemaAlojamiento`.
